# 2D Full Portfolio Website

A complete, responsive, interactive 2D portfolio website with zero build tools required.

## How to Open
- Double-click `index.html` to open it directly in your browser, **or**
- Serve the folder with any static server (e.g. VS Code Live Server or `npx serve .`).

## How to Edit Later (2 Easy Ways)

### Option 1: Edit Visually in the Browser
1. Open `index.html` and click **✎ Edit Site** (top-right) or **✎ Edit Portfolio** (bottom-right).
2. Update your Profile, Theme Colors, About, Skills, Projects, and Experience — changes preview live and auto-save in your browser.
3. Click **⬇ Download config.js** and replace `config.js` in this folder to save your changes permanently.

### Option 2: Edit `config.js` Directly
Open `config.js` in any code editor and update `window.PORTFOLIO_CONFIG` (name, bio, projects, skills, experience, colors, links).
